# SaniZ for Mac 사용법

화면을 확대하고 그 위에 그림 · 글씨를 쓰는 도구예요. 화면 일부를 오려 **항상 맨 위에 띄워 두는 게시 모드**도 있습니다. (macOS 14 Sonoma 이상, Apple 실리콘 · 인텔 맥 모두 지원)

Windows판 SaniZ의 맥 버전입니다. 실행하면 메뉴 막대(화면 오른쪽 위)에 형광펜 아이콘으로 상주하고, 아래 단축키로 바로 씁니다.

<br>

## 📦 설치

1. `SaniZ-mac-1.0.0.dmg` 를 내려받아 열고, **SaniZ** 를 **응용 프로그램** 폴더로 끌어다 놓습니다.
   (`.zip` 을 받았다면 압축을 풀고 `SaniZ.app` 을 응용 프로그램 폴더로 옮기면 됩니다)
2. 응용 프로그램 폴더에서 SaniZ 를 엽니다.

> ⚠️ **처음 열 때 "열 수 없습니다" / "확인되지 않은 개발자" 경고가 뜨면** — Apple 유료 개발자 인증을 받지 않은 개인 제작 프로그램이라 뜨는 정상 안내입니다(바이러스 아님).
>
> 1. 경고창에서 **완료**(또는 취소)를 누릅니다.
> 2. **시스템 설정 → 개인정보 보호 및 보안** 으로 가서 아래쪽의 *"SaniZ이(가) 차단되었습니다"* 옆 **그래도 열기** 를 누릅니다.
> 3. 다시 한 번 **열기** 를 누르면 됩니다. 이후로는 그냥 열립니다.
>
> 터미널에 익숙하다면 이 한 줄로도 됩니다: `xattr -dr com.apple.quarantine /Applications/SaniZ.app`

### 화면 기록 권한

확대 · 판서 · 게시는 화면을 캡처하므로 **화면 기록 권한**이 필요합니다. 처음 단축키를 누를 때 요청이 뜨거나 화면이 검게 나오면:

1. **시스템 설정 → 개인정보 보호 및 보안 → 화면 및 시스템 오디오 기록**
2. **SaniZ** 를 켭니다
3. SaniZ 를 **종료한 뒤 다시 실행** (메뉴 막대 아이콘 → 종료)

<br>

## 🔑 모드 켜고 끄기

| 키 | 기능 |
|----|------|
| `⌥ + `` ` `` | **게시 모드** 켜기 / 끄기 |
| `⌥ + 1` | **확대 모드** 켜기 / 끄기 |
| `⌥ + 2` | **판서 모드** 켜기 / 끄기 |
| `⌥ + 3` | **편집 모드** 켜기 / 끄기 (판서 ↔ 편집 전환, 그린 내용 유지) |
| `Esc` | 종료 |

`⌥` 는 Option 키입니다 (Windows판의 Alt). 단축키는 설정에서 바꿀 수 있어요.

<br>

## 📌 게시 모드 (`⌥ + `` ` )

화면의 한 부분을 오려서 **항상 맨 위에 떠 있는 조각**으로 만듭니다. 참고 자료를 옆에 두고 수업할 때 씁니다.

- 켜면 화면이 어두워지고 **커서를 따라 "드래그를 통해 게시할 영역을 지정할 수 있습니다."** 안내가 붙어 다녀요.
- **드래그** → 그 영역이 조각으로 떠오릅니다. 한 번 지정하면 게시 모드는 자동으로 꺼져요. 여러 개 붙일 수 있습니다.
- **조각은 어떤 모드에서도 항상 화면 맨 위에 있습니다.**
- 조각 위에서 — **드래그** 위치 이동 · **휠** 크기 조절 · **우클릭** 그 조각 삭제
- 조각을 만져도 발표 중인 앱(키노트 · 파워포인트 등)의 포커스를 뺏지 않습니다.
- 메뉴 막대 아이콘 → **"게시된 조각 모두 닫기"** 로 한 번에 정리.

<br>

## 🔍 확대 모드 (`⌥ + 1`)

- **마우스 이동** → 커서를 따라 확대
- **마우스 휠** → 확대 배율 조절
- **좌클릭** → 그 화면 그대로 멈추고 **판서 모드로 자동 전환**

<br>

## ✏️ 판서 모드 (`⌥ + 2`)

**그리기**

| 입력 | 기능 |
|------|------|
| 드래그 | 자유 곡선 |
| `⌃` + 드래그 | 사각형 (테두리) |
| `⌃ + ⇧` + 드래그 | 채운 사각형 |
| `⇧` + 드래그 | 직선 |

**색 · 텍스트 · 지우개 · 배경**

| 키 | 기능 |
|----|------|
| `R` / `G` / `B` / `Y` / `I` | 펜 색 (빨강 / 초록 / 파랑 / 노랑 / 아이보리) |
| `T` | 텍스트 입력 (누른 뒤 위치 클릭 → 입력, `⇧+Return` 줄바꿈, `Return` 완료) |
| `S` | 숫자 스탬프 (누른 뒤 찍을 자리 클릭) |
| `E` | 지우개 켜기 / 끄기 |
| 마우스 휠 | 펜 굵기 · 글자 크기 · 지우개 크기 즉석 조절 |
| `K` / `W` | 어두운 / 밝은 배경 |
| `⌘Z` (또는 `⌃Z`) | 마지막 동작 되돌리기 |
| `⌘E` (또는 `⌃E`) | 판서 내용 전체 삭제 |

마지막으로 쓴 색과 휠로 바꾼 굵기 · 크기는 다음에 켜도 그대로 이어집니다. 한글은 조합 중인 글자가 그 자리에 바로 그려집니다.

<br>

## ✂️ 편집 모드 (`⌥ + 3`)

판서 모드에서 그린 뒤 `⌥3`으로 전환하면, 배경은 그대로 두고 **그려둔 펜 · 텍스트만** 옮길 수 있어요.

- **드래그** → 사각형 영역 선택
- **선택 영역 안을 드래그** → 사각형 안에 들어온 부분만 이동
- `⌫` → 선택 영역 삭제

<br>

## ⚙️ 설정

메뉴 막대 아이콘 → **설정…**

- **단축키** — 게시 · 확대 · 판서 · 편집. 칸을 누르고 원하는 조합을 그대로 누르면 됩니다 (`⌫` 로 지움)
- **색** — 펜 5색(R G B Y I), 배경 2색(K W)
- **그리기** — 확대 배율, 펜 굵기, 지우개 크기, 텍스트 크기(pt), 텍스트 글꼴 (직접 설치한 글꼴 포함)
- **기타** — 로그인 시 자동 실행

**기본값** 단추로 처음 상태로 되돌릴 수 있습니다.
