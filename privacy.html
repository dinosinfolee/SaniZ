개인정보처리방침

시행일: 2026년 10월 24일

SaniZ(이하 "본 프로그램")는 화면 확대 · 판서 · 게시를 위한 수업 도구입니다. 본 프로그램은 사용자의 개인정보를 수집하지 않습니다.

1. 수집하는 정보

본 프로그램은 이름, 연락처, 계정 정보, 기기 식별자, 사용 기록 등 어떠한 개인정보도 수집하지 않습니다.

2. 화면 캡처와 판서 내용

  • 확대 · 판서 · 게시 모드를 켜면 그 순간의 화면을 캡처하여 사용자의 컴퓨터 메모리 안에서만 처리합니다.
  • 캡처한 화면과 판서 내용은 모드를 끄면 즉시 메모리에서 삭제되며, 디스크에 저장되지 않습니다.
  • 사용자가 화면 저장(Ctrl + S)을 실행한 경우에만, 사용자가 지정한 위치에 이미지 파일로 저장됩니다.

3. 외부 전송

본 프로그램은 인터넷 연결을 사용하지 않으며, 화면 · 판서 내용 · 설정을 저작자 또는 제3자에게 전송하지 않습니다.

4. 설정 저장

단축키 · 펜 색 · 글꼴 · 크기 등의 설정은 사용자의 컴퓨터(Windows 레지스트리)에만 저장됩니다. 프로그램을 제거하면 함께 삭제됩니다.

5. 사용자의 책임

저장하거나 공유한 화면 이미지의 관리, 그리고 화면에 표시된 개인정보의 보호는 사용자의 책임입니다.

6. 문의

본 방침에 관한 문의는 GitHub 저장소를 통해 남겨 주십시오.
