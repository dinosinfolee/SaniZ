실행하기

SaniZ.exe를 실행하면 트레이에 아이콘이 추가됩니다. 아이콘을 두 번 누르면 설정 창이 열립니다.

3

보호 안내가 나타나면

서명되지 않은 개인 제작 프로그램이라 나타나는 정상 안내입니다. 추가 정보 › 실행을 누릅니다.

새 버전으로 교체하기 — 기존 SaniZ를 종료하지 않고 새 버전을 실행하면, 기존 프로그램이 자동으로 종료되고 새 버전으로 교체됩니다. 같은 버전이나 더 낮은 버전을 실행하면 교체되지 않고 기존 프로그램이 유지됩니다. (v1.5.0부터 적용)

응용 프로그램 폴더로 옮겨 실행합니다

실행하면 메뉴 막대에 아이콘이 상주합니다. 설정은 메뉴 막대 아이콘 › 설정…에서 엽니다.

1

내려받기

위의 내려받기 단추로 압축 파일을 받은 뒤, SaniZ를 응용 프로그램 폴더로 끌어다 놓습니다.

2

열 수 없다는 안내가 나타나면

Apple 개발자 인증을 받지 않은 개인 제작 프로그램이라 나타나는 정상 안내입니다. 안내 창을 닫은 뒤 시스템 설정 › 개인정보 보호 및 보안에서 그래도 열기를 누릅니다.

3

화면 기록 권한 허용

화면을 캡처하므로 권한이 필요합니다. 시스템 설정 › 개인정보 보호 및 보안 › 화면 및 시스템 오디오 기록에서 SaniZ를 켠 뒤 다시 실행합니다.

터미널을 사용하는 경우 — 다음 명령 한 줄로 2단계를 대신할 수 있습니다. xattr -dr com.apple.quarantine /Applications/SaniZ.app

모드 안내

네 가지 모드를 단축키로 전환합니다

모드를 켠 순간의 화면이 정지되어, 그 위에 작업합니다. 판서 · 편집 모드를 오가도 그린 내용은 유지됩니다.

게시 모드

Alt + ~⌥ + `
  • 드래그로 영역을 지정하면 그 부분이 조각으로 떠오릅니다.
  • 조각은 어떤 모드에서도 항상 화면 맨 위에 유지됩니다.
  • 조각 위에서 드래그로 이동, 휠로 크기 조절, 우클릭으로 삭제합니다.
  • 조각을 조작해도 발표 중인 앱(키노트 · 파워포인트 등)의 포커스를 가져가지 않습니다.

확대 모드

Alt + 1⌥ + 1
  • 마우스를 움직이면 확대 화면이 커서를 따라갑니다.
  • 마우스 휠로 확대 배율을 조절합니다.
  • 좌클릭하면 그 화면이 정지되고 판서 모드로 전환됩니다.

판서 모드

Alt + 2⌥ + 2
  • 곡선 · 직선 · 사각형 · 텍스트 · 숫자 스탬프를 작성합니다.
  • 커서 옆 배지에 현재 도구와 크기가 표시됩니다.
  • 마지막으로 사용한 색과 크기는 다음 실행에도 유지됩니다.

편집 모드

Alt + 3⌥ + 3
  • 배경은 그대로 두고 판서한 내용만 옮깁니다.
  • 드래그로 영역을 선택하고, 선택 영역 안을 드래그하여 이동합니다.
  • 선택 사각형 안에 들어온 부분만 이동하고 나머지는 제자리에 유지됩니다.
  • ⌫를 누르면 선택 영역을 삭제합니다.

주요 특징

수업 흐름을 방해하지 않습니다

가볍게 상주

사용하지 않을 때는 트레이메뉴 막대에서 대기하며 자원을 거의 사용하지 않습니다. 단축키를 누르는 즉시 동작합니다.

한글 바로 입력

조합 중인 글자가 입력 위치에 바로 표시됩니다. 별도 입력창이 나타나지 않습니다.

원하는 대로 설정

단축키 · 펜 색 · 배경색 · 글꼴 · 크기를 바꿀 수 있습니다. 직접 설치한 글꼴도 선택할 수 있으며, 설정은 자동으로 저장됩니다.

본 프로그램은 화면 및 판서 내용을 저작자 또는 제3자에게 전송하지 않으며, 인터넷 연결을 사용하지 않습니다. 설정은 사용자의 레지스트리(HKCU\Software\SaniZ)에만 저장됩니다. 저장하거나 공유한 화면 이미지의 관리, 그리고 화면에 표시된 개인정보의 보호는 사용자의 책임입니다.
